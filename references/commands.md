# 命令全集

所有命令在 `scripts` 目录执行。表名可用中文或英文简写；
字段名写中文即可（如 `姓名`、`单位`、`学时`），脚本自动翻译成后端字段。

## 导入

```
node index.js 导入 <文件> [--table 人员|计划|名额|记录|规则] [--wide] [--sheet 工作表名]
```

| 参数 | 说明 |
|---|---|
| `--table` | 不传时自动识别文件属于哪张表 |
| `--wide` | 用于「名额分配」这种 单位×班次期次 的交叉表，自动拍平 |
| `--sheet` | 指定工作表名，不传则自动挑选命中最高的 |

示例：
```bash
node index.js 导入 "D:/培小e输入/人员表.xlsx"
node index.js 导入 "D:/培小e输入/计划表.xlsx" --table plan
node index.js 导入 "D:/培小e输入/计划表.xlsx" --wide
```

## 查询

```
node index.js 查询 <表> [--条件 字段=值] [--like 字段=值] [--字段 a,b,c]
                       [--排序 字段] [--倒序] [--页 N] [--每页 N]
```

| 参数 | 说明 |
|---|---|
| `--条件` | 等值匹配，可重复 |
| `--like` | 模糊匹配，可重复 |
| `--字段` | 只返回指定列，逗号分隔 |
| `--排序` / `--倒序` | 排序字段与方向 |
| `--页` / `--每页` | 默认第 1 页、每页 20 条，每页最大 500 |

示例：
```bash
node index.js 查询 人员 --like 姓名=张 --字段 姓名,单位 --每页 10
node index.js 查询 记录 --条件 单位=济南公司 --排序 学时 --倒序
```

## 导出与模板

```
node index.js 导出 <表> [--输出 文件路径]
node index.js 模板 <表> [--输出 文件路径]
```
不传 `--输出` 时落在「输出」文件夹。导出的列与批注与导入模板完全一致。

## 修改与删除（用业务字段定位，不需要主键）

```
node index.js 改 <表> 定位字段=值 [...] 字段=新值 [...] [--预览]
node index.js 删 <表> 定位字段=值 [...] [--预览]
```

| 表 | 定位字段（任选其一组） |
|---|---|
| 人员 | 员工编号 |
| 计划 | 年度 + 班次 + 期次 |
| 名额 | 年度 + 班次 + 期次 + 单位（自动换成计划编号） |
| 记录 | 员工编号 + 年度 + 班次 + 期次 |
| 规则 | 规则名称 或 规则编码 |

定位字段之外写的都是要改的字段；必须唯一命中一条才执行，执行前打印「原值 → 新值」，`--预览` 只看不写。
也可以直接用主键（人员标识、计划编号等）定位。删除是软删。

```
node index.js 改 人员 员工编号=00044250 任职时间=2026-03-01
node index.js 改 计划 年度=2027 班次=四级领导人员进修班 期次=第一期 调训规则="2026年已参加本班次的不重复"
node index.js 改 名额 年度=2027 班次=四级领导人员进修班 期次=第一期 单位=济南公司 名额=6
node index.js 改 规则 规则名称=参培对象限制 是否启用=0
node index.js 删 记录 员工编号=00044250 年度=2026 班次=四级领导人员进修班 期次=第一期 --预览
```

改了规则原文或计划的参培对象/调训规则后，下次 `名单` 会只让变化的条款重新翻译和审核。

## 出名单（一条命令自动推进）

```
node index.js 名单 --年度 2027 [--每单位上限 N] [--输出 目录]
node index.js 名单 --复现 "<运行记录_2027.json.gz>"
```

`名单`（旧名 `建议` 仍可用）每次从接口取最新数据，按状态推进并打印下一步：

| 状态 | 它做什么 | 退出码 | 下一步 |
|---|---|---|---|
| 有条款待翻译 / 被驳回 | 写 `输出/规则解析/待翻译规则.json` | 2 | 模型按 [规则识别与人工审核](rule_dsl.md) 填写 → `规则 登记` → 再跑 `名单` |
| 有条款待审核 | 生成 `规则审核表_年度.xlsx`（含试算） | 3 | 用户审核 → `规则 确认 "<审核表>"` → 再跑 `名单` |
| 全部已确认 | 出建议名单 Excel/HTML + `运行记录_年度.json.gz` | 0 | — |

`--复现` 用运行记录里的输入快照和已确认条款重算，核对结果指纹是否一致。

## 规则子命令

```
node index.js 规则 登记 [文件] [--覆盖]     校验并登记模型翻译的草稿（待审核）；一条不合格全部不登记
node index.js 规则 确认 "<审核表.xlsx>"     读回用户审核（审核人必填）：确认/修改 → 已确认；驳回 → 退回重译
node index.js 规则 查看 [--年度 2027]       中文列出每个条款的状态与筛选条件
node index.js 规则 审计 [--年度 2027]       检查审核日志完整性，列出每次确认的审核人、保存程序、用时与疑点
node index.js 规则 审核表 [--年度 2027]     需要复核时重新出完整审核表
```

## 看板

```
node index.js 看板 --年度 2027 [--输出 文件路径]
```

## 自检与帮助

```
node index.js 自检     检查接口配置、后端连通、结果目录可写、图表库、Excel 解析环境
node index.js 帮助     显示全部命令
```

`自检` 会逐项打印结论（✓ 表示通过、× 表示失败并给出处理建议），
任何命令出问题先跑它。

## 身份

默认使用本机 `scripts/config.local.json`（或环境变量）里的管理员凭据；也可加 `--account <姓名> --credential <身份证后四位>`
以普通用户身份执行（普通用户只能看本人数据与本单位计划、名额）。
