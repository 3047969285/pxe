# 命令全集

所有命令在 `scripts` 目录执行。表名可用中文或英文简写；
字段名写中文即可（如 `姓名`、`单位`、`学时`），脚本自动翻译成后端字段。

## 导入

```
node index.js 导入 <文件> [--table 人员|计划|名额|记录|规则] [--wide] [--sheet 工作表名]
```

| 参数 | 说明 |
|---|---|
| `--table` | 不传时自动识别文件属于哪张表 |
| `--wide` | 用于「名额分配」这种 单位×班次期次 的交叉表，自动拍平 |
| `--sheet` | 指定工作表名，不传则自动挑选命中最高的 |

示例：
```bash
node index.js 导入 "D:/培小e输入/人员表.xlsx"
node index.js 导入 "D:/培小e输入/计划表.xlsx" --table plan
node index.js 导入 "D:/培小e输入/计划表.xlsx" --wide
```

## 查询

```
node index.js 查询 <表> [--条件 字段=值] [--like 字段=值] [--字段 a,b,c]
                       [--排序 字段] [--倒序] [--页 N] [--每页 N]
```

| 参数 | 说明 |
|---|---|
| `--条件` | 等值匹配，可重复 |
| `--like` | 模糊匹配，可重复 |
| `--字段` | 只返回指定列，逗号分隔 |
| `--排序` / `--倒序` | 排序字段与方向 |
| `--页` / `--每页` | 默认第 1 页、每页 20 条，每页最大 500 |

示例：
```bash
node index.js 查询 人员 --like 姓名=张 --字段 姓名,单位 --每页 10
node index.js 查询 记录 --条件 单位=济南公司 --排序 学时 --倒序
```

## 导出与模板

```
node index.js 导出 <表> [--输出 文件路径]
node index.js 模板 <表> [--输出 文件路径]
```
不传 `--输出` 时落在「输出」文件夹。导出的列与批注与导入模板完全一致。

## 修改与删除

```
node index.js 改 <表> 主键字段=值 字段=新值 [字段=新值 ...]
node index.js 删 <表> 主键字段=值
```
各表主键：人员 `人员标识` / 计划 `计划编号` / 名额 `名额标识` /
记录 `记录编号` / 规则 `规则编号`。
删除是软删，数据仍在库中。

## 建议名单与看板

```
node index.js 建议 --年度 2027 [--每单位上限 N] [--输出 目录]
node index.js 看板 --年度 2027 [--输出 文件路径]
```

## 其它

```
node index.js 帮助                       显示全部命令
node index.js 查询 规则 --每页 1          连通性自检
```

## 身份

默认使用 `config.js` 里的管理员凭据；也可加 `--account <姓名> --credential <身份证后四位>`
以普通用户身份执行（普通用户只能看本人数据与本单位计划、名额）。
