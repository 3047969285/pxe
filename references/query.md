# 查询指南

```
node index.js 查询 <表> [--条件 字段=值] [--like 字段=值] [--字段 a,b,c]
                       [--排序 字段] [--倒序] [--页 N] [--每页 N]
```

## 一、表名

中文：人员 / 计划 / 名额 / 记录 / 规则
英文简写：leader / plan / quota / record / rule

## 二、字段写中文

脚本会自动把中文翻成后端字段，不用记英文：

| 中文 | 对应 |
|---|---|
| 姓名、人员姓名 | 人员表的姓名 |
| 单位 | 人员表/名额表的单位；记录表里指「参培时所在单位」 |
| 员工编号、员工ID | 员工编号 |
| 班次名称、班次 | 班次名称 |
| 期次 | 期次 |
| 学时 | 本次学时 |
| 累计学时、总学时 | 累计培训学时 |
| 身份证号 | 身份证号（普通用户查询会自动脱敏） |

## 三、运算符（命令行只暴露最常用的）

| 命令行写法 | 作用 |
|---|---|
| `--条件 单位=济南公司` | 等值匹配 |
| `--like 姓名=张` | 模糊匹配（包含） |
| `--排序 学时 --倒序` | 排序 |

底层接口支持 14 种运算符（EQ/NE/GT/GE/LT/LE/LIKE/NOT_LIKE/IN/NOT_IN/BETWEEN/IS_NULL/IS_NOT_NULL），
需要更复杂的条件时可直接按 [接口契约](api_contract.md) 调 `/query`。

## 四、分页与选列

```bash
node index.js 查询 人员 --每页 50            # 每页条数，最大 500
node index.js 查询 人员 --页 3               # 第 3 页
node index.js 查询 人员 --字段 姓名,单位      # 只返回这两列
```

不传分页参数时默认第 1 页、每页 20 条。

## 五、权限（自动生效）

| 身份 | 能查到什么 |
|---|---|
| 管理员 | 五张表全量 |
| 普通用户 | 本人资料与记录、本单位名额、本单位已分配名额的计划 |

普通用户查人员表时，身份证号只显示后四位，其余打星号。

## 六、输出形式

结果是中文对齐表格，不输出原始 JSON：

```
【查询结果 · 领导人员信息】
  共 22 条，当前第 1 页，本页显示 3 条

  姓名    单位      身份证号
  ────────────────────────────────────
  张云欣  东营公司  370102198405212449
```

内容过长的列自动截断加省略号。
