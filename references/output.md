# 产物说明

## 一、结果放哪

**所有产物只落在一个地方：技能包同级的「输出」文件夹。**

```
培小e\
├── scripts\
├── templates\
├── samples\
├── 输入\       待导入的 Excel（可选）
└── 输出\       ★ 所有产物只落这里
```

约定：

| 规则 | 说明 |
|---|---|
| 单一出口 | 导出、模板、建议名单、看板一律落「输出」，不散落别处 |
| 自动创建 | 目录不存在时程序自动建 |
| 文件名中文 | 如 `通用规则.xlsx`、`培训记录导入模板.xlsx`，不出现英文表名 |
| 无过程文件 | 中间文件只写系统临时目录、用完立即删；「输出」里只有最终产物 |
| 成组存放 | 同一批产物集中一个文件夹，便于整体拷贝 |
| **按日期归档** | 结果落在「输出\2026-10-12\」这样的日期子目录，多次运行互不覆盖 |
| **操作日志** | 每次执行追加一行到「输出\操作日志.txt」：时间、命令、结果，可事后追溯 |

换位置：改 `scripts/config.js` 的 `outDir`，或单次命令加 `--输出 <路径>`；
不需要按日期分子目录时，把 `outputByDate` 改成 `false`；不需要日志则关掉 `operationLog`。

### 目录形态

```
输出\
├── 操作日志.txt
├── 2026-10-12\
│   ├── 通用规则.xlsx
│   ├── 培小e建议名单_2027.xlsx
│   ├── 培小e建议名单_2027.html
│   ├── 培小e看板_2027.html
│   └── echarts.min.js
└── 2026-10-13\
    └── ……
```

操作日志样例：

```
[2026-10-12 14:10:59] 成功  导出  通用规则 7 条 -> .\输出\2026-10-12\通用规则.xlsx
[2026-10-12 14:11:02] 成功  建议名单  11 个班次 / 500 人次
```

## 二、Excel 产物

| 来源 | 文件 | 内容 |
|---|---|---|
| `导出 <表>` | `<表名>.xlsx` | 该表数据，**列与批注与导入模板完全一致**，改完可直接导回 |
| `模板 <表>` | `<表名>导入模板.xlsx` | 空白模板：表头带批注（含【必填】/【可选】与说明）+ 4 行样例 |
| `建议 --年度 Y` | `培小e建议名单_Y.xlsx` | 建议名单 / 剔除与顺延 / 按期次汇总 三个工作表 |

模板特点：
- 每个表头带**批注**，鼠标悬停可见「必填还是可选、是什么意思、怎么填」
- 每个工作表有 **4 行浅色样例**，覆盖各种取值（启用/停用、有编码/无编码、有学时/无学时等），填报前删掉即可
- 首行冻结

## 三、HTML 产物

| 来源 | 文件 | 内容 |
|---|---|---|
| `建议 --年度 Y` | `培小e建议名单_Y.html` | 剔除原因分布 / 各期次建议与计划对比 / 各单位建议人次 / 建议明细（自动滚动） |
| `看板 --年度 Y` | `培小e看板_Y.html` | 6 个核心指标 + 干部级别分布 / 各期次计划人数 / 各单位人员分布 / 各单位记录数 |

特点：
- **深色国网大屏风格**，一屏铺满，不用缩放
- **自包含**：数据内嵌，图表库同目录（`echarts.min.js`），拷到任何机器双击即开
- **内网可用**：图表库随产物一起输出，不依赖外网
- **界面全中文**，不出现英文

## 四、无英文承诺

除以下两处外，模板与产物中不出现英文：

1. 规则表的「规则编码」内部使用（但**模板已不展示此列**，用户看不到）
2. 无需用户接触的脚本与配置
