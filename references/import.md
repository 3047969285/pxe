# 导入指南

## 一、自动识别

不传 `--table` 时，脚本会扫描前 12 行找表头，按表头命中的字段数判断文件属于哪张表。
识别结果会打印在命令行（如「识别为：领导人员信息，共 1665 条数据」）。

命中的表头越多越准。一个文件里多个工作表时，自动挑命中最高的那个。

## 二、表头容错

中文表头允许写简称或全称，都能认：

| 数据库字段 | 可识别的表头写法 |
|---|---|
| 人员姓名 | 姓名 / 人员姓名 |
| 员工编号 | 员工ID / 员工编号 / 员工号 / 编号 |
| 身份证号 | 身份证号 / 身份证号码 / 身份证 |
| 是否为党支部书记 | 是否为党支部书记 / 是否党支部书记 / 是否党委 |
| 累计培训学时 | 累计培训学时 / 总学时 / 培训学时 |
| 参培时间 | 参培时间 / 培训时间 / 培训周期 |

表头行不必在第 1 行（标题行、说明行都可以在前面），脚本自动定位。

## 三、自动规范化

| 原始写法 | 处理结果 |
|---|---|
| `2027年3月16日至3月30日` | 拆成开始日期 `2027-03-16`、结束日期 `2027-03-30`、年度 `2027` |
| `2018年7月` | 入职时间 → `2018-07-01`（只有年月时按当月 1 日） |
| Excel 日期序列号（如 `43952`） | 转成 `2020-05-01` |
| `第一期` / `第1期` / `1` | 统一为「第一期」 |
| 员工编号 `00044250` | 保留前导零，不会变成 `44250` |

## 四、名额分配交叉表（--wide）

「名额分配表」是 17 家单位 × 11 个班次期次的交叉表，需要拍平成行式：

```
        新提任正职班        县班子进修班   …
        第一期  第二期      第一期  第二期
济南公司    4       4           5       5
青岛公司    4       4           6       6
```

执行 `--wide` 后，每一格变成一行：`(计划年度, 班次, 期次, 单位, 名额)`，
再按「年度+班次+期次」自动匹配到培训计划编号，共 187 行。

**导入顺序**：先导培训计划，再导名额分配，否则匹配不到计划编号。

## 五、自动回填的字段

用户不需要填这些，系统自己算：

| 字段 | 怎么来 |
|---|---|
| 培训计划的编号 | 导入时按 年度+班次+期次 匹配 |
| 培训记录的计划编号 | 同上 |
| 名额分配的计划编号 | 同上 |
| 规则的编码 | 按规则名称自动生成，同名规则复用同一编码 |
| 创建时间 / 更新时间 / 删除标志 | 数据库自动 |
| 人员的累计学时、培训记录 | 由培训记录表自动汇总 |

## 六、常见导入问题

| 现象 | 原因与处理 |
|---|---|
| 提示「未解析到有效数据行」 | 表头没被识别，或必填列缺值。先跑 `--sheet` 指定工作表，或核对表头写法 |
| 提示「第 N 行缺少必填字段」 | 该行必填列为空，脚本会跳过并提示，其余行照常导入 |
| 提示「未匹配到培训计划」 | 名额/记录导入前没先导培训计划，或班次名称与计划表不一致 |
| 提示「识别为：未知表」 | 文件不属于 5 张表，或表头完全对不上，需显式 `--table` |
| 导入成功但条数比预期少 | 看命令行提示的「跳过」信息，通常是缺必填字段 |

## 七、幂等性

所有写入按业务唯一键 UPSERT（有则更新、无则新增）：

| 表 | 业务唯一键 |
|---|---|
| 人员信息 | 员工编号 |
| 培训计划 | 年度 + 班次名称 + 期次 |
| 名额分配 | 计划编号 + 单位 |
| 培训记录 | 员工编号 + 年度 + 班次 + 期次 |
| 通用规则 | 规则名称（同名复用编码） |

所以同一份 Excel 导多少遍都不会产生重复数据。
