# 规则引擎与建议名单

## 一、怎么用

```bash
node index.js 建议 --年度 2027              # 生成应训未训建议名单
node index.js 建议 --年度 2027 --每单位上限 3  # 限制每个单位最多建议几人
node index.js 看板 --年度 2027              # 生成统计看板
```

产物落在「输出」文件夹：建议名单 Excel（3 个工作表）+ HTML，看板 HTML。

## 二、算出来的名单包含什么

| 工作表 | 内容 |
|---|---|
| 建议名单 | 每个班次期次建议谁去：单位、姓名、级别、累计学时、评分、优先级、推荐理由 |
| 剔除与顺延 | 谁被剔除、触发哪条规则、什么原因 |
| 按期次汇总 | 每期计划人数、建议人数、剔除人次 |

当前实测：11 个班次、建议 500 人次、剔除 17815 人次。

## 三、计算流程（固定）

```
读规则表 → 识别规则 → 逐班次筛人 → 硬规则过滤 → 软规则打分排序 → 按单位名额取数 → 出名单
```

硬规则**先**执行（不满足直接剔除），全部通过后再跑软规则累加得分，
最后按单位名额上限取名次靠前的人。

## 四、支持的七条规则

| 规则 | 类型 | 判定 |
|---|---|---|
| AB角不得同出 | 硬 | 与已入选者的 B 角冲突则剔除 |
| 重复参培剔除 | 硬 | 本年度已排其它班次、或上年度同类班次则剔除 |
| 生产分管负责人避开春秋检 | 硬 | 培训期与 3.1–6.30、9.1–11.30 重叠则剔除 |
| 参培对象限制 | 硬 | 满 55 岁不进进修班；非正/副职不进新提任班 |
| 近3年未参培优先 | 软 | 按距上次参培年数给分 30/12/0 |
| 学时缺口优先 | 软 | 按累计学时给分 25/12/0 |
| 党支部书记专场 | 软 | 进修班第五期 +35 分，其它班次 −20 分 |

## 五、规则怎么配置

规则在 `pxe_training_rule` 表维护（模板：`templates/培小e-通用规则导入模板.xlsx`）：

| 列 | 说明 |
|---|---|
| 规则类型 | 硬规则 或 软规则 |
| 规则名称 | 如「硬规则一：AB角不得同出」 |
| 规则内容 | 写明判定条件 |
| 是否启用 | 填 1 启用、0 停用；留空视为启用 |

**规则编码不需要填** —— 导入时按规则名称自动生成，同名规则复用同一编码。
**优先级不需要填** —— 按你在 Excel 里的行序自动编排执行次序。

## 六、识别机制（为什么能适配不同规则）

引擎有两层识别，保证用户上传不同写法也能用：

1. **按编码识别** — 编码是已知的（如 `HARD_AB_ROLE`）直接分派对应执行器；
2. **按关键词兜底** — 编码认不出时，扫规则名称与内容里的关键词
   （含「春秋检」「AB角」「学时」「党支部书记」等）挂到对应执行器；
3. **仍认不出** — 列入 `unknown` 提示，**不猜、不静默跳过**。

## 七、停用规则

把「是否启用」改成 `0` 即可停用，规则仍留在表中，改回 `1` 恢复。
